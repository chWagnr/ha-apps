# Home Assistant Apps

For new installations, add `https://github.com/chWagnr/ha-apps` to the Home Assistant app store. If you already added `https://github.com/chWagnr/hassio-addons`, keep that URL in Home Assistant. GitHub redirects it to this repository, and keeping the original URL preserves your installed app IDs.

- [CertFlow](certflow/README.md)
- [Papra](papra/README.md)
- [Tandoor MCP](tandoor-mcp/README.md) — authenticated recipe access and import for MCP clients.
- [Nextcloud MCP](nextcloud-mcp/README.md) — nc_mcp_server for Nextcloud apps, including Cospend.

Changelogs werden nach Versionsänderungen auf `main` automatisch aus den App-Commits ergänzt und über einen Changelog-PR gemergt. Vorhandene Einträge bleiben erhalten. Der PR-Check prüft vorhandene oder probeweise erzeugte Einträge; Platzhalter und doppelte Versionseinträge schlagen fehl. Der Update-Workflow lässt sich auch manuell auf `main` starten, um fehlende Einträge nachzuholen.
