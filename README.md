Changelogs werden nach Versionsänderungen auf `main` automatisch aus den App-Commits ergänzt und über einen Changelog-PR gemergt. Vorhandene Einträge bleiben erhalten. Der PR-Check prüft vorhandene oder probeweise erzeugte Einträge; Platzhalter und doppelte Versionseinträge schlagen fehl. Der Update-Workflow lässt sich auch manuell auf `main` starten, um fehlende Einträge nachzuholen.
